# Root & Jailbreak Rehberi

Modern, sade ve güvenli anlatımlı rehber portalı.

## İçerik
- Ana sayfa
- Rehberler sayfası
- AI destek sayfası
- Yasal ve etik uyarı sayfası
- Cihaz bazlı rehberler
- Risk ve fayda bölümleri

## Çalıştırma
Bu proje statik HTML/CSS/JS kullanır. Projeyi yerelde açmak için:

1. Dosyaları klonlayın.
2. `index.html` dosyasını bir tarayıcıda açın.

## GitHub Pages
GitHub Pages'i açmak için:

1. GitHub repo sayfasına gidin.
2. `Settings` > `Pages`
3. Source: `Deploy from a branch`
4. Branch: `main`
5. Folder: `/ (root)`
6. Save

Site URL örneği:
https://codeand-art.github.io/root-jailbreak-guide/

## Yasal uyarı
Bu proje eğitsel amaçlıdır. Kullanan kişinin sorumluluğu ve riskleri kendi kendine değerlendirmesi gerekir.
